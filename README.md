One 100-word villain monologue, written to `/output/entry.txt`: a dark lord three hundred years into his scheme — the eclipse, the crown, the kingdom kneeling, Thursday or next week — who never says he is tired, but shows it in every deflection, from the cat with seniority to the couch at the end.

## Run it

```sh
python3 main.py
```

Writes the monologue to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python stdlib, deterministic — the same 100 words every run.
